# Φωτογραφίες

Οι φωτογραφίες του site **δεν** αποθηκεύονται στο git, γιατί εικονίζουν ανηλίκους και δεν
έχει ακόμα επιβεβαιωθεί η συγκατάθεση των γονέων για δημοσίευση.

Για να δουλέψει το site με εικόνες τοπικά, αντιγράψτε εδώ τους φακέλους
`agelh/`, `omada/`, `koinotita/`, `eks/`, `vathmoforoi/` και το `afisa-agiasmos.jpg`
(ζητήστε τα από τον υπεύθυνο του site). Χωρίς αυτά, το site χτίζεται κανονικά αλλά οι
φωτογραφίες εμφανίζονται κενές.

Όταν υπάρξει συγκατάθεση, αφαιρέστε τη γραμμή `/public/images/*` από το `.gitignore`.
Περισσότερα στον [οδηγό προγραμματιστή](../../docs/DEVELOPER_GUIDE.md) (§5.2 και §8).
