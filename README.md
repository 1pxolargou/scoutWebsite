# Πρόσκοποι Χολαργού: ιστοσελίδα

Στατική ιστοσελίδα του 1ου Συστήματος Προσκόπων Χολαργού (Next.js + Tailwind CSS).
**Πλήρης οδηγός για προγραμματιστές** (εγκατάσταση σε Windows/Linux, δομή, προσθήκη και αφαίρεση περιεχομένου και λειτουργιών, Facebook token, δημοσίευση): [docs/DEVELOPER_GUIDE.md](docs/DEVELOPER_GUIDE.md).

## Τοπική εκτέλεση

Χρειάζεται Node.js 20.9 ή νεότερο.

```bash
npm install
```

Για ανάπτυξη, με αυτόματη ανανέωση στο http://localhost:3000:

```bash
npm run dev
```

Για να βγάλετε το στατικό site στον φάκελο `out/`:

```bash
npm run build
```

Για να δείτε το στατικό site στο http://localhost:4173:

```bash
npm run preview
```

Ο φάκελος `out/` περιέχει απλά αρχεία HTML/CSS/JS και εικόνες, που μπορούν να ανέβουν σε
οποιονδήποτε στατικό hosting.

## Πού αλλάζει το περιεχόμενο

| Τι                                                 | Πού                                                                              |
| -------------------------------------------------- | -------------------------------------------------------------------------------- |
| Αριθμοί, τμήματα, ώρες, email, URL φόρμας εγγραφών | `site.config.ts`                                                                 |
| Εκδηλώσεις                                         | `content/events/*.mdx` (πρότυπο: `content/_templates/event.mdx`)                 |
| Άλμπουμ φωτογραφιών                                | `content/albums/*.mdx` (πρότυπο: `content/_templates/album.mdx`)                 |
| Κείμενα τμημάτων                                   | `content/sections/*.mdx`                                                         |
| Ιστορία, Βαθμοφόροι, FAQ, carousel                 | `content/*.json`                                                                 |
| Φωτογραφίες                                        | `public/images/`                                                                 |
| Ενδεικτικά νέα (μέχρι να συνδεθεί το Facebook)     | `content/mock/facebook-posts.json`                                               |
| Προφίλ Βαθμοφόρων (όνομα, εκπαιδεύσεις, σημείωμα)  | `content/leaders.json`                                                           |
| Ιστορικό αρχείο: ένα αρχείο ανά χρονιά             | `content/archive/1985-86.json` (πρότυπο: `content/_templates/archive-year.json`) |
| Δελτίο Υγείας, στοιχεία πληρωμής (Περιοχή Μελών)   | `site.config.ts` → `members` και `public/files/`                                 |

Το build ελέγχει όλο το περιεχόμενο. Αν λείπει κάποιο υποχρεωτικό πεδίο (π.χ. `alt` ή
`allowPublish` σε φωτογραφία), σταματά και λέει σε ποιο αρχείο είναι το πρόβλημα.

## Εισαγωγή ιστορικού αρχείου από Excel / Google Sheets

Το φύλλο έχει μία γραμμή ανά χρονιά και τις στήλες: **Χρονιά, Επιτελείο Συστήματος, Επιτελείο
Αγέλης, Επιτελείο Ομάδας, Επιτελείο Κοινότητας, Κατασκήνωση Αγέλης, Κατασκήνωση Ομάδας, Μεγάλη
Δράση Κοινότητας**. Η σειρά των στηλών δεν έχει σημασία. Παράδειγμα:
`content/_templates/archeio-paradeigma.csv`.

- **Χρονιά:** `1985-86`, `1985–1986` ή σκέτο `1986`.
- **Επιτελεία:** ονόματα χωρισμένα με κόμμα ή αλλαγή γραμμής. Ρόλος σε παρένθεση, π.χ.
  `Γιώργος Παπαδόπουλος (Ακέλα)`.
- **Κατασκηνώσεις:** ο τόπος (π.χ. `Ελάτη, Τρικάλων`).
- **Μεγάλη Δράση Κοινότητας:** οι στάσεις με τη σειρά, χωρισμένες με `-` ή `→`. Προαιρετικός
  τίτλος με άνω-κάτω τελεία: `Ζαγόρι: Μονοδένδρι - Βίκος - Πάπιγκο`.

Βήματα:

1. Google Sheets: _Αρχείο → Λήψη → Τιμές διαχωρισμένες με κόμματα (.csv)_. Excel: _Αποθήκευση ως
   → CSV UTF-8_.
2. Βάλτε το αρχείο στον φάκελο του site (π.χ. `archeio.csv`). Τα `.csv`/`.xlsx` εκεί δεν μπαίνουν
   στο git.
3. Τρέξτε:

```bash
npm run import:archive -- archeio.csv --clean
```

Το `--clean` σβήνει τις ενδεικτικές χρονιές που δεν υπάρχουν στο CSV. Αν το σκέτο `1999` στο
φύλλο σημαίνει τη χρονιά 1998–99, προσθέστε `--year-ends`.

Οι συντεταγμένες βρίσκονται αυτόματα από το OpenStreetMap (στέλνονται μόνο ονόματα τόπων) και
αποθηκεύονται στο `content/archive/_places.json`. Όσοι τόποι δεν βρεθούν εμφανίζονται στο τέλος:
συμπληρώστε `lat`/`lng` εκεί με το χέρι (δεξί κλικ στον χάρτη του Google Maps δίνει τις
συντεταγμένες) και τρέξτε ξανά. Οι σημειώσεις (`note`) που γράψατε με το χέρι σε μια χρονιά
διατηρούνται.
